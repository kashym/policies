# Policies

Public landing pages for privacy policies across Kashyman apps, hosted via
GitHub Pages. One subfolder per app.

Live at: https://kashym.github.io/policies/

This repo intentionally contains no app source code — it exists solely to
host public privacy policy pages while each app's main repository can stay
private.
